# حزمة المعاينة — Unified Dose PWA

هذه حزمة محلية لتحويل مرشح v5 إلى تطبيق ويب قابل للتثبيت. إنها نسخة معاينة وليست إصدارًا معتمدًا للاستخدام السريري. لم تُغيّر عمدًا المعادلات أو الجرعات أو سجلات العلاجات عند إضافة ملفات PWA.

## الملفات
- `index.html`: نسخة v5 المحلية مع ربط Manifest وتسجيل Service Worker.
- `manifest.webmanifest`: اسم التطبيق ومظهره وأيقوناته.
- `service-worker.js`: تخزين غلاف التطبيق محليًا بعد أول تحميل ناجح لدعم إعادة الفتح دون اتصال في الحدود الممكنة.
- `icons/`: أيقونات PNG بمقاسي 192 و512.

## المعاينة على أندرويد
1. ارفع محتويات المجلد إلى مستودع اختبار منفصل أو موقع اختبار منفصل؛ لا تستبدل الموقع الحالي.
2. فعّل GitHub Pages للمستودع التجريبي، بحيث يعمل الموقع عبر HTTPS.
3. افتح رابط HTTPS في Chrome على الهاتف وانتظر اكتمال التحميل مرة واحدة أثناء الاتصال.
4. من قائمة Chrome اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» إذا ظهر الخيار.
5. اختبر البحث واختيار العلاج والإضافة والحذف والتصدير والاستيراد وإعادة الفتح، ببيانات تجريبية فقط.

## حدود مهمة
- فتح الملف مباشرة من `file://` لا يكفي لتسجيل Service Worker؛ يلزم HTTPS أو localhost.
- التخزين المؤقت لا يضمن أن كل الموارد الخارجية أو جميع خصائص المتصفح تعمل دون اتصال.
- لم يُجرَ حتى الآن اختبار تشغيل آلي كامل داخل متصفح؛ فحص الصياغة الثابت لا يعادل اعتمادًا سريريًا أو جاهزية نهائية للنشر.
- أبقِ هذه المعاينة منفصلة عن الموقع العام الحالي حتى تتم الموافقة صراحةً.
